# GuildQuest Mini-Adventure Environment (GMAE)

## Run

From project root:

```bash
javac Frontend/*.java Backend/*.java Backend/Tiles/*.java Backend/Maps/*.java
java Frontend.GMAEGUI
```

## Requirements

- Java 17+ recommended.
- Local two-player play on one machine.

## Mini-adventures

- Relic Hunt
- Timed Raid (time-window objective)
