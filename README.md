# GuildQuest Mini-Adventure Environment (GMAE)
Nathaniel Heit, Lance Vu, Logan Szeto, Grace Jong, Maiella Nuqui

## Run

From project root:

```bash
java -jar GMAE.jar
```

## Requirements

- Java 17+ recommended.
- Local two-player play on one machine.

## Mini-adventures

- Relic Hunt
- Timed Raid (time-window objective)
